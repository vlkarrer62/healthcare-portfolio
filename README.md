# Veronica Hollabaugh — Healthcare Portfolio

A portfolio focused on clinical operations, digital health, patient safety, and utilization management.

## Featured projects

- **Kodama Health** — Clinician-guided CBT program for tinnitus, hyperacusis, and misophonia. Launched to a founding cohort; patient outcomes have not been reported.
- **ENT surgical handoff redesign** — Multidisciplinary laterality verification workflow adopted after a near miss.
- **Provider onboarding** — Interactive concept prototype for an AI-assisted credentialing journey; uses fictional data and does not submit information.

Additional case studies explore nursing ambient documentation adoption and an Ohio native plant guide.

## Run locally

Open `index.html` in a browser. `onboarding-demo.html` contains the simulated intake experience. The site uses HTML, CSS, and vanilla JavaScript without a build step.

## Transparency

Illustrative metrics and conceptual work are labeled. This public repository should not contain patient-identifiable information. The onboarding prototype is not a production credentialing service.
